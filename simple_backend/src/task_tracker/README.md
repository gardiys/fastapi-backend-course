**Хранение состояния** - это когда данные хранятся в оперативной памяти, а не во внешнем хранилище.

### МИНУСЫ  
 - При перезапуске сервера временное хранилище опустошается
 - Не масштабируется, т.е. если серверов несколько, данные не синхронизируются
---
**Что изменилось при сохранении в файл вместо оперативной памяти:**  
 - Задачи не пропадают после перезапуска  
 - Данные теперь надежнее хранятся  

**Где еще хранить задачи:**  
 - Базы данных, облако, Redis 
---
**Что изменилось после перехода на облачное хранилище:**  
 - Задачи хранятся в облаке
 - Можно масштабировать
 - Сервер ничего не запоминает, все берет из внешнего API

### МИНУСЫ  
 - Возможны задержки
 - Потенциальные проблемы с безопасностью
