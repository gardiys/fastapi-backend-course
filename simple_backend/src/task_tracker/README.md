### Минусы хранения задач в оперативной памяти:

1. Потеря данных при перезагрузке
2. Отсутствует возможность масштабируемости. При запуске нескольких экземпляров, каждый экземпляр будет иметь свою копию данных
3. Ограничение по обьему оперативной памяти клиента

### Изменения
1. После добавления tasks.json мы избавились от хранения состояния. 
2. Все доабвляемые таски теперь сохраняются в файл и там же остаются после перезагрузки приложения. 
3. Можно делать бэкапы, только для этого сохранять предыдущую версию файла, что неудобно.
4. Можно вручную править файл и смотреть, что там сохранилось

Задачи можно хранить в БД. Из минусов - сложность. Из плюсов - надежность и версионность без копирований файлов как в случае с json.
