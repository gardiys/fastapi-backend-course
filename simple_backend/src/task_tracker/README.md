Минусы хранения задач в оперативной памяти:
1. Данные теряются при перезапуске приложения
2. При запуске в нескольких воркерах у каждого будет отдельный список, т.к. нет общей памяти между
процессами
3. Невозможно эффективно искать, фильтровать и т.д.


Выводы по хранению задач в файле
1. Теперь отсутствуют проблемы под п.1 и п.2 из прошлого раздела
2. Мы не избавились от хранения состояния, т.к. по-прежнему файл хранится
на нашем севере, а не на каком-то стороннем ресурсе
3. Задачи также можно хранить в:
   * БД (удобная фильтрация, но более сложная реализация и высокая ресурсоемкость);
   * Облачное хранилище (масштабируемость, но зависимость от внешних сервисов)
   * Кэш-системы (например, Redis) (быстрый доступ, но данные могут быть потеряны при перезапуске)
