



















Вопрос : "Прочитайте что такое "состояние гонки" и напишите в readme файле о том, какие проблемы остались 
в бекенде на данном этапе проекта. Есть ли у вас какое-то решение этой проблемы?"

Ответ на вопрос: В данном проекте существует проблема когда несколько пользователей делаю запросы, данные начинают храниться локально
и вследствие этого когда кто-то вносит изменения, то пользователь вносит эти изменения в уже старую копию так-как другой
пользователь мог сделать это гораздо быстрее. 
Один из способов решение это хранить в json-объекте поле "_version" или хэш, и проверяйте перед отправкой, 
не изменился ли файл.
