# Хранение данных в оперативной памяти
## Плюсы
 - Высокая скорость доступа
 - Простота реализации полезно для тестирование или прототипирования
## Минусы
 - Данные в оперативной памяти теряются при перезагрузке приложения
 - Ограниченный объем памяти и дорогая память по сравнение с хранением на физическом носителе
 - Проблема с конкурентным доступом что требует блокировки  иди других механизмов синхронизации
 - Риски переполнения памяти
## Итог
    Рационально использовать данный подход если нужно что-то быстро протестировать либо показать реализацию ,
    какой-то задумки когда нету времени поднимать и набрасывать схему для бд или для фаила
