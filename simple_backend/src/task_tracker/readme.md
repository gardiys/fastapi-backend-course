    Преимущества:
        Возможность выполнения сложных запросов
        Возможность совместной работы
    Недостатки:
        Сложная настройка и обслуживание
Облачные сервисы:
    Преимущества:
        Возможность совместной работы
        Интеграция с другими сервисами
    Недостатки:
        Скорость работы зависит от интернет-соединения
