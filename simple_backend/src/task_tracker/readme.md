Минусы подхода с хранением задач в оперативной памяти (списке Python)

1. Потеря данных при завершении работы приложения:
   Все данные о задачах теряются при завершении работы программы, что делает этот метод ненадежным для долговременного хранения.

2. Отсутствие долговечности:
   Данные, которые хранятся в памяти, не могут быть восстановлены после перезапуска программы, что требует дополнительных мер для их сохранения (например, сохранение в файл или базу данных).

3. Ограничения по объему данных:
   Оперативная память ограничена, и с увеличением объема данных программа может столкнуться с нехваткой памяти.

4. Проблемы с многозадачностью и параллельностью:
   Когда приложение использует многозадачность или многопоточность, данные, хранящиеся в оперативной памяти, могут привести к проблемам с синхронизацией данных.

5. Медленное масштабирование:
   При росте данных приложение, использующее хранение в памяти, может столкнуться с трудностями масштабирования, что потребует перехода на более сложные механизмы хранения данных, такие как базы данных.
