    - Прочитайте что такое "состояние гонки" и напишите в readme файле о том, какие проблемы остались в бекенде на данном этапе проекта. Есть ли у вас какое-то решение этой проблемы?

    в коде есть момент состояния гонки. он возникает из-за того, что данная система зависит от порядка выполнения операций несколькоми потоками. гонка появляется, если несколько пользователей одновременно пытаются создать, обновить, удалить задачу. 

    эту проблему можно решить путем:
    1. Блокировки
    будет блокировка доступа к данным другим пользователям, пока один выполняет запрос
    2. Очереди
    все операции будут собираться в очередь и выполняться поочередно 
    3. Версирование
    каждое изменение будет получать свою новую версию и перед сохранением будет проверяться не изменилось ли что либо
